## 🟢 基础层（正常结构和功能）

### [[卡片/消化系统/消化道大体解剖|消化道大体解剖]]
📖 *食管(颈/胸/腹三段，三个狭窄)、胃(贲门/胃底/胃体/胃窦/幽门)、小肠(十二指肠/空肠/回肠)、大肠(盲肠/阑尾/升结肠/横结肠/降结肠/乙状结肠/直肠/肛管)。胃肠壁四层：黏膜→黏膜下层→肌层(环+纵)→浆膜/外膜。* → 《系统解剖学》消化系统章

### [[卡片/消化系统/肝、胆、胰解剖|肝、胆、胰解剖]]
📖 *肝=最大内脏器官，Couinaud分段(8段)，双重血供(门静脉75%+肝动脉25%)。胆道系统：肝内胆管→左右肝管→肝总管+胆囊管→胆总管→十二指肠乳头(Oddi括约肌)。胰=胰头/胰体/胰尾，有外分泌(腺泡→胰液)+内分泌(胰岛)。* → 《系统解剖学》消化系统章

### [[卡片/消化系统/消化系统组织学|消化系统组织学]]
📖 *胃黏膜：表面上皮(黏液细胞)+胃小凹→胃底腺(主细胞=胃蛋白酶原，壁细胞=HCl+内因子，颈黏液细胞)。小肠绒毛+微绒毛→吸收面积最大化，隐窝干细胞→上皮更新。肝小叶=六角形，中央静脉+放射状肝索+肝血窦+毛细胆管。* → 《组织学与胚胎学》消化系统章

### [[卡片/消化系统/消化液分泌|消化液分泌]]
📖 *胃液：HCl(壁细胞分泌→pH<2，H⁺-K⁺-ATP酶即质子泵→杀菌+激活胃蛋白酶原+促进铁/钙吸收)+内因子(结合VitB12→回肠吸收)。胰液：HCO₃⁻+消化酶(胰蛋白酶原/糜蛋白酶原/胰淀粉酶/胰脂肪酶)→被肠激酶激活。胆汁：胆盐(乳化脂肪)+胆红素+胆固醇。* → 《生理学》消化章

### [[卡片/消化系统/胃肠动力|胃肠动力]]
📖 *食管下括约肌(LES)防反流。胃：容受性舒张(接纳食物)+蠕动(混合+研磨+排空)。胃排空速率：糖>蛋白质>脂肪。小肠：分节运动(混合)+蠕动(推进)。大肠：集团蠕动(每日1-3次)。胃肠运动的调控：ENS+ANS(交感↓/副交感↑)+胃肠激素。* → 《生理学》消化章

### [[卡片/消化系统/营养物质的消化与吸收|营养物质的消化与吸收]]
📖 *糖→单糖(SGLT1/GLUT2)。蛋白质→氨基酸/二肽/三肽(PepT1)。脂肪→乳化→脂肪酶水解→混合微胶粒→被动扩散→重新酯化→乳糜微粒→淋巴管。VitB12在回肠与内因子结合后被吸收。铁在十二指肠以Fe²⁺被DMT1吸收。* → 《生理学》消化章 / 《生物化学》物质代谢章

### [[卡片/消化系统/肝脏代谢与生化|肝脏代谢与生化]]
📖 *肝是代谢中枢：糖代谢(糖原合成/分解/糖异生)、脂代谢(脂肪酸β氧化/酮体生成/脂蛋白合成)、蛋白质代谢(尿素合成/血浆蛋白合成/转氨)。生物转化：两相反应(Ⅰ相氧化还原水解→Ⅱ相结合→增加水溶性→排泄)。胆红素代谢：血红素→胆绿素→间接胆红素→肝细胞结合→直接胆红素→胆汁。* → 《生物化学》肝的代谢章

## 🟡 桥梁层（正常→异常的过渡）

### [[卡片/消化系统/消化性溃疡病生|消化性溃疡病生]]
📖 *"攻击-防御失衡"：攻击因素(HCl/胃蛋白酶/HP/NSAIDs)，防御因素(黏液-碳酸氢盐屏障/黏膜血流/前列腺素/上皮更新)。HP→尿素酶分解尿素产氨→生存于酸性环境→炎症→胃泌素↑→酸↑→溃疡。NSAIDs→COX↓→PG↓→黏膜防御↓。* → 《病理生理学》消化章

### [[卡片/消化系统/肝硬化病生|肝硬化病生]]
📖 *各种慢性肝损伤(病毒/酒精/脂肪/胆汁淤积)→肝细胞坏死→纤维增生→假小叶形成→门脉高压。门脉高压后果：(1)脾大/脾功能亢进；(2)侧支循环开放(食管胃底静脉曲张/痔静脉/脐周静脉)；(3)腹水。肝功能失代偿：(1)合成↓→凝血因子↓/白蛋白↓→水肿；(2)灭活↓→雌激素↑；(3)解毒↓→肝性脑病。* → 《病理生理学》肝病章

### [[卡片/消化系统/胰腺炎病生|胰腺炎病生]]
📖 *"自身消化"：胰酶在胰腺内过早激活(胰蛋白酶原→胰蛋白酶→激活所有酶→胰腺组织自身消化)。诱因：胆石嵌顿/酒精刺激/高脂血症。全身反应：炎症因子释放→SIRS→MODS(ARDS/急性肾损伤)。坏死性胰腺炎比水肿性预后差得多。* → 《病理生理学》消化章

### [[卡片/消化系统/黄疸的鉴别诊断|黄疸的鉴别诊断]]
📖 *三步法：(1)检查结合/非结合胆红素→溶血性(非结合↑)vs肝细胞性(双↑)vs梗阻性(结合↑)；(2)看尿胆原/尿胆红素→梗阻性(尿胆红素+/尿胆原-)；(3)GGT/ALP→胆道酶升高=梗阻。* → 《诊断学》黄疸章

### [[卡片/消化系统/腹泻与吸收不良|腹泻与吸收不良]]
📖 *渗透性腹泻(未吸收溶质→水潴留，禁食好转)vs分泌性腹泻(肠上皮主动分泌→水/电解质，禁食不停止)。脂肪泻=脂肪吸收↓→粪便油腻恶臭。乳糖不耐受=乳糖酶缺乏→乳糖→肠道细菌发酵→气体+渗透性腹泻。* → 《病理生理学》消化章

### [[卡片/消化系统/消化系统药理基础|消化系统药理基础]]
📖 *抑酸药：PPI(奥美拉唑→不可逆抑制H⁺-K⁺-ATP酶→最强)、H₂拮抗剂(雷尼替丁→抑制组胺促酸)。胃黏膜保护：铋剂/硫糖铝。促动力：多潘立酮/莫沙必利。止吐：5-HT₃拮抗剂(昂丹司琼)。保肝：甘草酸/水飞蓟素。利胆：熊去氧胆酸。* → 《药理学》消化系统药物章

### [[卡片/消化系统/腹部查体|腹部查体]]
📖 *视(膨隆/舟状腹/蠕动波/腹壁静脉曲张)、听(肠鸣音活跃/减弱/消失)、叩(鼓音/移动性浊音=腹水)、触(压痛/反跳痛/肌紧张=腹膜刺激三联征；Murphy征=胆囊炎；McBurney点压痛=阑尾炎；肝脾触诊)。* → 《诊断学》腹部查体章
