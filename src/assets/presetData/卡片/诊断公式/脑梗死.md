## 6. 如果现在是医生
- 症状：突发一侧肢体无力/麻木、口角歪斜、言语不清
- 体征：偏瘫、偏身感觉障碍、病理征阳性（Babinski征+）
- 检查：头颅CT（排除出血）+ MRI/DWI + 颈动脉超声 + 心电图（排除房颤）
- 治疗：4.5h内阿替普酶静脉溶栓 + 抗血小板 + 他汀 + 控制危险因素
