# 二尖瓣解剖

## 1. 一句话

二尖瓣不是"两个瓣叶"这么简单——它是一个精密的复合装置：瓣环+前/后瓣叶+腱索+乳头肌+左房室壁，五者协同才能正常开闭。任何一个环节出问题，都会导致二尖瓣关闭不全。

## 2. 定位

系统：心血管系统　　层：🟢 基础
课程：系统解剖学

## 3. 踩在什么上面（纵向向下）

- [[卡片/心血管系统/心脏大体解剖|心脏大体解剖]] — 知道左房室口的位置和二尖瓣在四瓣膜中的方位
- 结缔组织与胶原纤维的基本结构 — 瓣叶是纤维弹性组织，需同时满足柔韧（易打开）和强度（对抗左室收缩压）

## 4. 通向哪里（纵向向上）

- [[卡片/心血管系统/二尖瓣狭窄|二尖瓣狭窄]] — 瓣口面积<2cm²→左房压↑→肺静脉压↑→呼吸困难
- [[卡片/心血管系统/二尖瓣关闭不全|二尖瓣关闭不全]] — 收缩期反流→左房/左室容量超负荷→房颤+心衰
- [[卡片/心血管系统/二尖瓣脱垂（MVP）|二尖瓣脱垂（MVP）]] — 瓣叶收缩期突入左房→喀喇音+晚期收缩期杂音
- [[卡片/心血管系统/急性心肌梗死|急性心梗→乳头肌断裂]] — 急性二尖瓣关闭不全→急性肺水肿→心源性休克

## 5. 还有哪里类似（横向类比）

- [[卡片/心血管系统/三尖瓣解剖|三尖瓣]] — 同样是房室瓣（瓣环+瓣叶+腱索+乳头肌），但在低压右心→反流常见且耐受性好，二尖瓣反流后果更严重（左室压高，反流量大）
- 主动脉瓣/肺动脉瓣 — 半月瓣没有腱索和乳头肌→房室瓣=腱索断裂致急性反流；半月瓣=钙化致狭窄

## 6. 如果现在是医生（临床反向）

- **二尖瓣听诊**：心尖区（第5肋间左锁骨中线），S1（房室瓣关闭）+ S2（半月瓣关闭），心尖区最易听到二尖瓣病变→舒张期隆隆样杂音=狭窄，收缩期吹风样杂音=关闭不全
- **急性二尖瓣反流 vs 慢性二尖瓣反流**：急性（腱索断裂/乳头肌缺血）→左房大小正常但突然承受大量反流→左房压力急剧↑→急性肺水肿（急症！）；慢性→左房逐渐扩大代偿→可以耐受多年
- **二尖瓣狭窄的病理生理链**：狭窄→左房压↑→肺静脉压↑→肺动脉压↑→右室后负荷↑→右心衰竭（这就是为什么二尖瓣狭窄的病人最严重时出现的是**右心衰竭**的症状——肝大/腹水/下肢水肿）
