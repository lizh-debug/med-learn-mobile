# 急性心肌梗死

## 1. 一句话

冠脉粥样硬化斑块破裂→血栓形成→冠脉急性闭塞→心肌缺血坏死。诊断=胸痛+ECG（STEMI/NSTEMI）+肌钙蛋白。治疗核心=时间就是心肌：尽快再灌注（PCI或溶栓）+双抗+他汀。

## 2. 定位

系统：心血管系统　　层：🔴 临床
课程：内科学

## 3. 踩在什么上面（纵向向下）

- [[卡片/心血管系统/心脏大体解剖|心脏大体解剖 — 冠脉分布]] — LAD→前壁/前间壁；LCX→侧壁；RCA→下壁/右室。ECG定位心梗的全部解剖基础
- [[卡片/心血管系统/心肌动作电位各期离子流|心肌动作电位 — 缺血电生理]] — 缺血→ATP↓→细胞外K⁺↑→Na⁺通道失活→传导减慢→折返→室颤（24h内最主要死因）
- [[卡片/心血管系统/动脉粥样硬化|动脉粥样硬化 — 斑块→血栓]] — 不稳定斑块破裂→血小板聚集→凝血级联→血栓→闭塞
- [[卡片/心血管系统/心动周期与心音|心动周期]] — 收缩期冠脉受压，心内膜下血供靠舒张期→心内膜最易缺血→ST改变最早出现

## 4. 通向哪里（纵向向上）

- [[卡片/心血管系统/急性心力衰竭|心梗后心力衰竭]] — 梗死面积>20%→射血分数↓→Killip分级→心源性休克（KillipⅣ死亡率>80%）
- [[卡片/心血管系统/心梗后机械并发症|心梗后机械并发症]] — 乳头肌断裂（急性二尖瓣反流+急性肺水肿）· 室间隔穿孔（右心衰+休克）· 游离壁破裂（心脏压塞→电机械分离）
- [[卡片/心血管系统/心律失常（室速/室颤）|心梗后心律失常]] — 室速/室颤（急性期最主要死因）· 加速性室性自主心律（再灌注标志）· 房室传导阻滞（下壁心梗→RCA供AV node）
- [[卡片/心血管系统/心室重构|心室重构]] — 梗死区变薄伸展→球形重构→远期心衰。ACEI/ARB+β阻滞剂的核心价值：延缓重构

## 5. 还有哪里类似（横向类比）

- [[卡片/心血管系统/不稳定性心绞痛|不稳定性心绞痛]] vs [[卡片/心血管系统/NSTEMI|NSTEMI]] vs STEMI — 同一条ACS谱系。UA=缺血无坏死（TnI-），NSTEMI=非透壁坏死（TnI+，ST↓），STEMI=透壁坏死（TnI+，ST↑）——处置逻辑完全不同
- [[卡片/呼吸系统/肺血栓栓塞症（PTE）|肺栓塞]] vs 心梗 — 都表现为胸痛+呼吸困难+ECG异常。PE=右室负荷+SIQIIITIII+TnI轻↑；心梗=左室损伤+ST/T改变+TnI↑↑。临床表现几乎一样但病理不同——胸痛的鉴别诊断核心
- [[卡片/心血管系统/应激性心肌病（Takotsubo）|应激性心肌病]] — 胸痛+ST↑+TnI↑=和心梗一模一样！但冠脉造影正常+心尖气球样膨出。儿茶酚胺风暴→心肌顿抑，不是血栓。鉴别=冠脉造影
- [[卡片/心血管系统/主动脉夹层|主动脉夹层]] — 撕裂样剧痛+可累及冠脉开口→继发心梗样ECG。**不可溶栓！溶栓会致命！**

## 6. 如果现在是医生（临床反向）

**诊断——"胸痛+ECG+肌钙蛋白"三步法**：
1. 胸痛=典型（胸骨后压榨感，持续>20min，硝酸甘油无效，伴大汗/濒死感/恶心）或不典型（老年/女性/糖尿病→可能仅有乏力/呼吸困难/上腹痛）
2. ECG=STEMI（损伤区→ST弓背向上抬高→对应导联可定位梗死部位）+对应导联的镜像压低
3. cTnI/cTnT↑（金标准，起病后3-6h升高，12-24h达峰→峰值与梗死面积呈正相关→3-10天恢复）+CK-MB（辅助，早期变化比TnI快→判断再梗时更敏感）

**治疗——四条同时启动**：
1. 再灌注（时间就是心肌）：<12h→PCI（最佳，90min内球扩）或溶栓（若PCI不可及<30min→30min内启动），溶栓失败→补救性PCI
2. 抗栓：双抗（阿司匹林+P2Y12抑制剂：替格瑞洛/氯吡格雷）+抗凝（肝素/低分子肝素/比伐卢定）
3. 稳定斑块与心肌保护：他汀（高强度，即刻启动）、β阻滞剂（心肌氧耗↓，除非有心衰/休克/心动过缓）、ACEI/ARB（重构↓，24h内启用）、硝酸酯类（前负荷↓→室壁张力↓→氧耗↓，若SBP>90）
4. 并发症监测：心律失常（持续心电监护+除颤仪备用）+心衰（Killip分级→利尿/血管扩张剂/正性肌力/IABP）+机械并发症（新杂音突然出现→超声=急！）
