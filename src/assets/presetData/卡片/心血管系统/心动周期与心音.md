# 心动周期与心音

## 1. 一句话

心脏每一跳包括收缩期（等容收缩→射血）和舒张期（等容舒张→充盈）。心音=瓣膜关闭的声响——S1是房室瓣关闭（收缩期开始），S2是半月瓣关闭（舒张期开始）。

## 2. 定位

系统：心血管系统　　层：🟢 基础
课程：生理学

## 3. 踩在什么上面（纵向向下）

- [[卡片/心血管系统/心肌兴奋-收缩耦联|心肌兴奋-收缩耦联]] — AP平台期Ca²⁺内流→触发收缩→收缩期泵血

## 4. 通向哪里（纵向向上）

- [[卡片/心血管系统/慢性心力衰竭|心力衰竭]] — 收缩功能障碍→每搏量↓→HFrEF；舒张功能障碍→充盈受限→HFpEF
- [[卡片/心血管系统/二尖瓣狭窄|二尖瓣狭窄]] — 舒张期左房→左室血流受阻→肺静脉压力↑→呼吸困难
- [[卡片/心血管系统/心脏杂音与心音听诊|心音听诊]] — S3（心衰）/ S4（左室肥厚）

## 5. 还有哪里类似（横向类比）

- 右室 vs 左室压力曲线形态相似，但绝对值不同——右室压峰≈25mmHg，左室压峰≈120mmHg（肺循环阻力=体循环的1/7）
- 骨骼肌泵（肌肉挤压静脉→静脉回流↑→前负荷↑→Frank-Starling机制增加每搏量）

## 6. 如果现在是医生（临床反向）

- **S3奔马律**（舒张早期附加音）→心室快速充盈期血液冲击已扩大的心室壁→心衰/容量超负荷时出现
- **S4奔马律**（舒张晚期附加音）→心房用力收缩将血液挤入僵硬的心室→左室肥厚/心肌缺血时出现
- **开瓣音**（OS，二尖瓣狭窄）→舒张期狭窄的二尖瓣开放到极限时突然停止→瓣膜活动尚好→提示可做球囊扩张
- **心包摩擦音**（心包炎）→三层而非四层，有"来回收缩"的刮擦感→与心音不同步
- **宽分裂S2**（呼吸时S2的A2-P2间距增大）→右束支传导阻滞/肺动脉高压→肺动脉瓣关闭延迟
