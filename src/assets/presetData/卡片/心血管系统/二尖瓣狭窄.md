# 二尖瓣狭窄

## 1. 一句话

二尖瓣口的面积从正常的4-6cm²缩小到<2cm²→舒张期左房到左室的血流受阻→左房压力↑→逆行性肺静脉压力↑→肺淤血→呼吸困难。风湿热是二尖瓣狭窄最常见病因，瓣叶增厚+交界粘连+腱索融合。

## 2. 定位

系统：心血管系统　　层：🔴 临床
课程：内科学

## 3. 踩在什么上面（纵向向下）

- [[卡片/心血管系统/二尖瓣解剖|二尖瓣解剖]] — 瓣叶增厚+交界粘连→瓣口面积↓→血流受阻。风湿主要累及瓣叶和交界；功能性MR则涉及乳头肌和左室壁
- [[卡片/心血管系统/心动周期与心音|心动周期]] — 舒张期左房→左室的压力梯度（正常2-4mmHg）在狭窄时显著增大
- [[卡片/心血管系统/心输出量调节|心输出量调节]] — 狭窄→左室舒张充盈↓→前负荷↓→每搏量↓。关键区别：收缩功能正常，是**充盈受阻**而非泵衰竭

## 4. 通向哪里（纵向向上）

- [[卡片/心血管系统/心律失常（房颤）|房颤]] — 左房压↑→左房扩大→电生理+结构重塑→多环路折返→房颤
- [[卡片/心血管系统/脑卒中（心源性栓塞）|心源性脑卒中]] — 房颤→左心耳血流淤滞→血栓→栓塞→脑/肾/肠系膜/下肢
- [[卡片/心血管系统/慢性心力衰竭|右心衰竭]] — 肺静脉高压→肺动脉高压→右室后负荷↑→右心衰→颈静脉怒张/肝大/腹水

## 5. 还有哪里类似（横向类比）

- [[卡片/心血管系统/三尖瓣狭窄|三尖瓣狭窄]] — 同样是房室瓣狭窄，但在右心→压力梯度更低（<5mmHg），远少见
- [[卡片/心血管系统/主动脉瓣狭窄|主动脉瓣狭窄]] — 同为"狭窄"，但发生在**收缩期**→左室后负荷↑→左室肥厚→心绞痛/晕厥/心衰。狭窄的时相（收缩vs舒张）决定了完全不同的病理生理
- [[卡片/心血管系统/缩窄性心包炎|缩窄性心包炎]] — 同样舒张期充盈受限→临床表现惊人相似（呼吸困难+右心衰），鉴别诊断中的必要考虑

## 6. 如果现在是医生（临床反向）

- **症状——一条逐渐递进的呼吸困难链**：劳力性呼吸困难（最早期）→端坐呼吸（平卧加重→夜间阵发性呼吸困难）→急性肺水肿（紧急！）。这条链的直接原因是左房压力随疾病进展逐步升高。
- **体征——听诊经典发现**：(1)心尖区舒张期隆隆样杂音（低音调→用钟型听头，左侧卧位+呼气末最清楚）；(2)开瓣音（OS，S2之后高频清脆→提示瓣膜活动度尚好→适合做经皮球囊二尖瓣成形术PBMV）；(3)S1响亮（因为左房压力高→心室收缩时瓣膜关闭的力更大）。如果S1变弱+OS消失→瓣膜钙化/纤维化重→不适合PBMV→需要换瓣。
- **咯血**（二尖瓣狭窄的经典症状）→支气管静脉破裂（支气管静脉回流到肺静脉→肺静脉压力↑↑→支气管静脉曲张→破裂→咯血）。这是二尖瓣狭窄导致肺静脉高压→支气管静脉破裂的直接病理生理链。
- **治疗决策**：PBMV（球囊扩张）vs 二尖瓣置换术→取决于瓣膜形态（超声Wilkins评分）——瓣叶增厚/钙化/交界粘连/腱索融合的程度
