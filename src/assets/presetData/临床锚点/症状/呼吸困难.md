# 呼吸困难

> **一句话**：呼吸困难=患者主观感觉"气不够用"。心肺疾病是第一梯队，但贫血、代谢性酸中毒、神经肌肉疾病、焦虑也在鉴别中。

## 核心分类

| 类型 | 机制 | 代表病因 |
|------|------|---------|
| 肺源性 | V/Q失调 / 弥散障碍 / 气道阻塞 / 限制性通气↓ | COPD/哮喘/肺炎/肺栓塞/间质性肺病/气胸 |
| 心源性 | 肺静脉高压→肺淤血→间质/肺泡水肿 | 左心衰（收缩性+舒张性）/ 二尖瓣狭窄 |
| 贫血性 | 携氧能力↓→组织缺氧→代偿性呼吸↑ | 严重贫血（Hb<60-70g/L） |
| 代谢性 | 代酸→化学感受器刺激→深大呼吸（Kussmaul） | DKA / 尿毒症 / 乳酸酸中毒 |
| 神经肌肉性 | 呼吸肌无力 / 呼吸中枢抑制 | GBS / 重症肌无力 / 药物（阿片类） |

## 反向追溯

### 基础层前置
- 呼吸力学（顺应性/气道阻力/呼吸功）
- 通气/血流比值（V/Q失调=分流+死腔样通气）
- 气体运输（HbO₂解离曲线右移→更容易释放O₂到组织）
- 心动周期与心输出量调节（前负荷/后负荷→心衰病生基础）

### 桥梁层
- 呼吸衰竭病生（Ⅰ型=换气障碍→PaO₂↓；Ⅱ型=通气不足→PaO₂↓+PaCO₂↑）
- 心衰病生（左心衰→肺静脉高压→从间质到肺泡→呼吸困难进行性加重：劳力性→端坐呼吸→夜间阵发性→急性肺水肿）
- 动脉血气分析
