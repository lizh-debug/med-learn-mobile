# 胸痛

> **一句话**：胸痛是心血管急症最重要的警示信号，但鉴别诊断涵盖心血管、呼吸、消化、骨骼肌等多个系统——"是不是心梗"是首要回答的问题。

## 鉴别矩阵

| 病因 | 疼痛特征 | 关键鉴别点 |
|------|---------|-----------|
| ACS/心梗 | 胸骨后压榨样，放射至左臂/下颌，持续>20min | ECG（ST-T改变）+ cTnI↑ |
| 主动脉夹层 | 撕裂样剧痛，前后胸，放射至背部 | 双上肢血压差>20mmHg + 纵隔增宽 |
| 肺栓塞 | 锐利胸痛+呼吸困难+咯血 | 下肢DVT证据 + D-二聚体 |
| 气胸 | 突然锐痛+呼吸困难 | 一侧呼吸音消失 + 气管偏移 |
| 心包炎 | 锐利，前倾位缓解 | 心包摩擦音 + 弥漫ST抬高（非冠脉分布） |
| 食管痉挛/反流 | 烧心样，平卧加重，制酸剂缓解 | PPI试验阳性 |
| 肋软骨炎 | 局限性压痛，触诊加重 | 有压痛点（非内脏性） |

## 反向追溯

### 基础层前置知识
- 心脏大体解剖 → 冠脉分布决定心梗定位
- 心肌动作电位 → 缺血电生理→ST改变+心律失常

### 桥梁层
- 动脉粥样硬化 → 斑块破裂→血栓
- 心电图基础 → ST段抬高/压低的电生理机制
