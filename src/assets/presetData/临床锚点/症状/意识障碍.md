# 意识障碍

> **一句话**：意识=觉醒（ARAS网状激活系统）+内容（大脑皮层）。意识障碍=ARAS失灵/双侧皮层失灵/两者皆失灵。GCS（睁眼+语言+运动）是最基本的评估工具。昏迷=结构性（需影像）+代谢性（需血检）两大类鉴别。

## 鉴别矩阵

| 病因 | 关键特征 | 确诊/排除方法 |
|------|---------|--------------|
| 低血糖昏迷 | 出汗+心悸+意识模糊→昏迷，Whipple三联征 | 指尖血糖<3.9mmol/L，补糖后恢复（最可逆的昏迷！急救第一位） |
| DKA/HHS昏迷 | 脱水+深大呼吸+烂苹果味+血糖↑↑ | 血糖+血酮+血气+渗透压 |
| 肝性脑病 | 黄疸+扑翼样震颤+肝臭+血氨↑+肝硬化史 | 血氨+临床分期（意识↓→昏迷） |
| 尿毒症脑病 | 尿毒症面容+皮肤尿素霜+Cr/BUN↑↑+代谢性酸中毒 | Cr/BUN+血气 |
| 脑卒中（大面积） | 突发+偏瘫+失语+凝视+高BP | CT→出血 vs 缺血→MRI |
| SAH | 霹雳样头痛→昏迷+Hunt-Hess分级 | CT平扫→LP |
| 脑膜炎/脑炎 | 发热+颈强直+头痛+意识↓ | LP→CSF |
| 癫痫持续状态 | 持续发作>5min或不恢复意识 | EEG+临床 |
| 药物/中毒 | 阿片（针尖瞳孔+呼吸↓→纳洛酮）/苯二氮䓬（氟马西尼）/CO中毒（樱桃红皮肤→COHb） | 毒物筛查 |
| 缺氧性脑病 | 心脏骤停后→6min内未恢复灌注→不可逆损伤 | 临床+EEG |
| 颅内占位/脑疝 | 进行性恶化+瞳孔不等大+Cushing三联征（BP↑+HR↓+呼吸不规则） | CT（紧急！） |

## 反向追溯

### 🟢 基础层前置
- [[]] — 意识的双组分（ARAS=脑干网状结构→丘脑→皮层→觉醒；双侧皮层=内容。结构性昏迷=ARAS被压或双侧皮层坏死；代谢性=弥漫性神经元功能障碍）
- [[]] — 颅内压调节（Monro-Kellie学说→代偿↓→ICP↑→CPP↓（CPP=MAP-ICP）→脑疝。瞳孔不等大=钩回疝→动眼神经→紧急！）
- [[]] — GCS（睁眼1-4+语言1-5+运动1-6=3-15分。≤8分=重度昏迷=气管插管指征）

### 🟡 桥梁层
- [[]] — 脑水肿病生（血管源性=BBB破坏→渗出；细胞毒性=缺氧→Na⁺/K⁺泵失灵→细胞肿胀；间质性=CSF压力↑→经室管膜渗出）
- [[]] — 肝性脑病（氨→星形细胞→谷氨酰胺↑→渗透性水肿→神经递质异常→GABA↑→意识↓。乳果糖→NH₃→NH₄⁺→排出；利福昔明→肠道菌↓→NH₃生成↓）
- [[]] — 脑死亡判定（不可逆的意识丧失+脑干反射消失+呼吸暂停试验阳性。和"植物状态"的区别：植物状态=丘脑+皮层死亡但脑干存活，有睡眠-觉醒周期但无意识）
