# 背痛

> **一句话**：背痛是失能的第一大原因。90%是非特异性（肌肉/韧带），但必须排除四大急症：主动脉夹层（撕裂样）、脊柱感染（发热+夜间痛）、马尾综合征（鞍区麻木+尿潴留）、肿瘤转移（夜间痛+体重↓）。"红flag"筛查优先于任何治疗。

## 鉴别矩阵

| 病因 | 疼痛特征 | 红flag | 确诊方法 |
|------|---------|--------|---------|
| 非特异性（机械性） | 活动加重，休息缓解，局限 | 无 | 临床诊断（排除法） |
| 椎间盘突出 | 放射至下肢（坐骨神经痛）+ 直腿抬高试验+ | 进行性肌力↓/排尿障碍→马尾 | MRI |
| 马尾综合征 | 双侧坐骨神经痛+鞍区麻木+尿潴留+肛门括约肌张力↓ | **外科急诊**→24h内必须减压 | MRI（紧急！） |
| 椎体压缩骨折 | 老年+骨质疏松+轻微外伤+局部叩痛 | 无 | X线→MRI（鉴别病理vs骨质疏松） |
| 脊柱感染（椎间盘炎/骨髓炎） | 持续性+夜间加重+休息不缓解+发热 | CRP/ESR↑+血培养+ | MRI增强+血培养/活检 |
| 脊柱转移癌 | 夜间痛（最特征！）+休息不缓解+体重↓+已知原发灶 | 夜间痛=恶性直到排除 | MRI+PET-CT+活检 |
| 主动脉夹层 | 撕裂样剧痛放射至背部+双上肢血压差>20mmHg | **致命急症** | CTA（金标准） |
| 急性胰腺炎 | 中上腹放射至背部（束带样）+淀粉酶/脂肪酶↑ | | 血淀粉酶/脂肪酶+CT |
| 肾结石 | 侧腰痛放射至腹股沟+血尿+辗转不安 | | CT平扫（非增强，高敏） |
| 强直性脊柱炎 | 炎性腰痛（晨僵+活动改善！）+HLA-B27+ | | 骶髂关节MRI→X线 |
| 带状疱疹 | 单侧烧灼/电击样+皮疹沿皮节分布 | 出疹前3-5天只有痛→最难诊断阶段 | 临床（皮疹确认） |

## 反向追溯

### 🟢 基础层前置
- [[]] — 脊柱解剖（椎体+椎弓+椎间盘+椎管+神经根。L4-L5+L5-S1=椎间盘突出90%→L5/S1神经根。马尾=L2以下神经根束→受压=双侧症状+括约肌）
- [[]] — 疼痛传导（窦椎神经→后纵韧带+硬膜+纤维环外层→腰痛的解剖基础；脊神经根→下肢放射痛=根性痛=running root）
- [[]] — 脊柱生物力学（前柱+中柱+后柱三柱模型→二柱骨折=不稳定→需手术）

### 🟡 桥梁层
- [[]] — 椎间盘退变病生（髓核脱水→纤维环撕裂→髓核突出。中央型→双侧症状。后外侧型→单侧根性症状。脱出/游离→最严重）
- [[]] — 马尾综合征（L2以下神经根→双侧坐骨神经痛+鞍区麻木S2-5+尿潴留+肛门括约肌张力↓。24h内必减压→否则永久性二便失禁+瘫痪）

## 关联系统骨架
- [[骨架/运动系统]] ← 椎间盘突出/骨折/关节炎/脊柱畸形（最常见）
- [[骨架/心血管系统]] ← 主动脉夹层（撕裂样背痛+BP差→致命急症！）
- [[骨架/消化系统]] ← 胰腺炎/溃疡穿孔→束带样放射至背部
- [[骨架/泌尿系统]] ← 肾结石/肾盂肾炎（侧腰→腹股沟+血尿）
- [[骨架/神经系统]] ← 脊髓受压/马尾综合征/脊髓炎/带状疱疹后神经痛
- [[骨架/免疫系统]] ← SpA/RA（颈椎受累→寰枢椎半脱位→脊髓受压！）
- [[骨架/血液系统]] ← 多发性骨髓瘤→溶骨→病理性压缩骨折+高钙+贫血
