# 发热

> **一句话**：发热=体温调定点上移（IL-1/IL-6/TNF-α→PGE₂→下丘脑前部），区别于高温症（调定点不变，散热不足）。发热类型（热型）和伴随症状缩小鉴别范围。

## 核心分类

| 类型 | 特征 | 代表病因 |
|------|------|---------|
| 感染性发热 | >90%，WBC↑/CRP↑/PCT↑ | 细菌/病毒/真菌/寄生虫 |
| 肿瘤性发热 | 无寒战，抗生素无效，萘普生试验阳性 | 淋巴瘤/肾癌/肝癌/骨肉瘤 |
| 自身免疫性发热 | 多系统受累+自身抗体+年轻女性 | SLE/成人Still病/RA/颞动脉炎 |
| 药物热 | 用药后出现，停药后消退 | β内酰胺/磺胺/苯妥英钠/异烟肼 |
| FUO | 发热>3周，体温多次>38.3℃，住院1周未确诊 | 感染(30%)/肿瘤(20%)/结缔组织病(15%) |

## 反向追溯

### 基础层
- 体温调节中枢（下丘脑前部→体温调定点）
- 固有免疫（PAMP→TLR→巨噬细胞→致热原→PGE₂合成酶COX-2）
- 白细胞分类与功能（中性粒↑=细菌，淋巴↑=病毒/结核，嗜酸粒↑=寄生虫/药物）

- 感染性疾病（跨系统）
