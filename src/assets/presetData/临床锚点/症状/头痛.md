# 头痛

> **一句话**：头痛分为原发性（偏头痛/紧张型/丛集性）和继发性（SAH/脑膜炎/颅内占位/颞动脉炎/颅内静脉窦血栓）。"霹雳样"头痛=SAH直到排除——这是神经科的"胸痛"级别急症。

## 鉴别矩阵

| 病因 | 关键特征 | 确诊/排除方法 |
|------|---------|--------------|
| 蛛网膜下腔出血(SAH) | 霹雳样头痛（瞬间达峰），颈强直 | CT平扫（24h内95%敏感）→LP查黄变 |
| 脑膜炎 | 发热+颈强直+头痛三联征 | LP→CSF（WBC↑/蛋白↑/糖↓） |
| 颅内占位 | 晨间加重，伴恶心呕吐，进行性加重 | MRI增强 |
| 偏头痛 | 单侧搏动性，持续4-72h，伴恶心/畏光/畏声 | 临床诊断（≥5次发作+符合特征） |
| 紧张型头痛 | 双侧压迫/紧箍感，轻中度，持续30min-7d | 临床诊断（排除器质性） |
| 丛集性头痛 | 单侧眶周剧痛+同侧结膜充血/流泪/Horner | 临床特征（发作周期性） |
| 颞动脉炎 | 老年人新发头痛+颞动脉压痛+ESR↑+下颌跛行 | 颞动脉活检（肉芽肿性血管炎） |
| 颅内静脉窦血栓 | 头痛+视乳头水肿+局灶神经体征 | MRV/CTV |
| 高血压危象 | 枕部头痛+BP↑↑+视乳头水肿 | BP监测+眼底检查 |
