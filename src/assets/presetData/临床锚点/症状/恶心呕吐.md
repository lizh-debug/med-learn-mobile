# 恶心呕吐

> **一句话**：呕吐反射=延髓呕吐中枢→CTZ（化学感受器触发区，血脑屏障外）或胃肠道迷走传入或前庭系统→协调的胃肠道+呼吸肌动作。三大类：胃肠道源/中枢神经源/代谢与药物源。

## 鉴别矩阵

| 病因 | 关键特征 | 确诊/排除方法 |
|------|---------|--------------|
| 急性胃肠炎 | 呕吐+腹泻+腹痛+发热，自限性1-3天 | 临床诊断+粪便培养 |
| 肠梗阻 | 胆汁性→粪样呕吐+腹胀+便秘+腹痛 | 立位腹平片（气液平+肠管扩张） |
| 幽门梗阻 | 呕吐宿食（含前一天食物）+胃振水音+低Cl⁻低K⁺代碱 | 胃镜+上消化道造影 |
| 急性胰腺炎 | 顽固性呕吐+中上腹痛放射至背+淀粉酶/脂肪酶↑ | 血淀粉酶/脂肪酶>3倍正常上限+CT |
| 颅内压增高 | 喷射性呕吐（无恶心前兆）+晨间头痛+视乳头水肿 | CT/MRI |
| 前庭性眩晕 | 恶心呕吐+眩晕+眼球震颤+耳鸣/听力↓ | Dix-Hallpike试验（BPPV）/HINTS（中枢vs周围） |
| DKA | 恶心呕吐+腹痛+深大呼吸+脱水+血糖↑↑ | 血糖+血酮+血气（AG↑代酸） |
| 药物/毒物 | 用药后出现（化疗/阿片/地高辛/酒精） | 用药史+停药试验 |
| 妊娠呕吐 | 停经+晨吐+hCG↑，孕6-14周高峰 | 尿hCG+超声 |
| 心梗（下壁） | 恶心呕吐+上腹痛+出汗+心血管危险因素 | ECG+TnI |

### 🟡 桥梁层
- [[]] — 肠梗阻病生（梗阻→肠腔压力↑→血供↓→缺血→细菌易位→脓毒症。胆汁性=十二指肠以下；粪样=远端/完全梗阻→最重要判断=有无绞窄）
