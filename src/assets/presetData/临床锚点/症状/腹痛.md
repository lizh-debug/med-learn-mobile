# 腹痛

> **一句话**：腹痛是急腹症最常见的就诊原因。内脏痛（定位模糊，痉挛/闷胀）+躯体痛（定位精确，锐利）+牵涉痛（内脏→体表）三种疼痛类型重叠是腹部诊断的核心难度。

## 按部位快速鉴别

| 部位 | 常见病因 |
|------|---------|
| 右上腹 | 胆囊炎/胆石症 · 肝炎 · 肝脓肿 · 十二指肠溃疡穿孔 |
| 中上腹 | 胰腺炎 · 胃溃疡 · 早期阑尾炎（内脏痛阶段） |
| 左上腹 | 脾梗死/破裂 · 胃溃疡 |
| 右下腹 | 阑尾炎 · 克罗恩病 · 异位妊娠（女性） · 卵巢扭转 · 输尿管结石 |
| 左下腹 | 憩室炎 · 溃疡性结肠炎 · 异位妊娠 · 卵巢扭转 |
| 弥漫 | 肠梗阻 · 肠穿孔→腹膜炎 · 肠系膜缺血 · 胃肠炎 |

## 反向追溯

### 基础层前置
- 消化道解剖（腹膜脏层无痛觉→内脏痛位置模糊；壁层=锐痛定位精确→炎症"渗透"到壁层=反跳痛/肌紧张）
- 牵涉痛机制（内脏传入+体壁传入同一脊髓节段会聚）
- 胃肠动力生理（正常蠕动模式→梗阻/蠕动亢进/麻痹）

### 桥梁层
- 胰腺炎病生（自身消化→酶激活级联→SIRS→MODS）
- 肠梗阻病生（梗阻→肠腔压力↑→血供↓→缺血→细菌易位→脓毒症）
- 黄疸鉴别（溶血性/肝细胞性/梗阻性→腹痛+黄疸立即缩小鉴别范围）

### 关联系统骨架
- [[骨架/消化系统]] ← 绝大多数腹痛病因
- [[骨架/泌尿系统]] ← 肾结石/肾盂肾炎（牵涉到侧腹/腹股沟）
- [[骨架/生殖系统]] ← 异位妊娠/卵巢扭转/PID/痛经
- [[骨架/心血管系统]] ← 腹主动脉瘤破裂（剧烈撕裂痛+低血压+搏动性腹部包块）
- [[骨架/内分泌系统]] ← DKA（腹痛呕吐可能误诊急腹症！）
