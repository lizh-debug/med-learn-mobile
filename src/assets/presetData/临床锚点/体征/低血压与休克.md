# 低血压与休克

> **一句话**：休克=组织灌注不足→细胞缺氧→代谢障碍→MODS。MAP<65mmHg是休克警报线。四大类型——分布性（血管床扩张→TPR↓，最常见）、低容量性（容量↓→CO↓）、心源性（泵衰竭→CO↓）、梗阻性（血流被物理阻塞→CO↓）——治疗方向截然相反。识别休克类型从床旁超声+乳酸开始。

## 反向追溯

### 🟢 基础层前置
- [[]] — MAP=CO×TPR（CO=HR×SV。SV取决于前负荷+后负荷+收缩力。TPR取决于血管平滑肌张力。任何一个环节崩溃→MAP↓→休克）
- [[]] — 氧输送与消耗（DO₂=CO×CaO₂≈CO×Hb×SaO₂×1.34；VO₂=DO₂×O₂ER。O₂ER=VO₂/DO₂。正常O₂ER=20-30%。休克→DO₂↓→O₂ER代偿↑→临界DO₂→O₂ER耗竭→VO₂↓→无氧代谢→乳酸↑）
- [[]] — 自主神经系统（交感→α1→血管收缩→SVR↑+β1→HR↑+收缩力↑=代偿。失代偿→交感耗竭→心功↓+血管扩张→不可逆=死亡）

### 🟡 桥梁层
- [[]] — 脓毒症病生（PAMP/DAMP→TLR→巨噬细胞→TNF/IL-1/IL-6→SIRS→iNOS→NO↑↑→血管扩张+毛细血管渗漏→分布性休克。同时→凝血系统激活→DIC。同时→线粒体功能障碍→细胞病性缺氧→O₂ER↓→SvO₂反↑=脓毒症特征！）
- [[]] — 心源性休克（泵衰竭→CO↓→MAP↓→冠脉灌注↓→心肌缺血加重→更严重的泵衰竭。螺旋恶化。IABP/Impella→恢复冠脉灌注→打破恶性循环）

### 🔴 临床层
- [[]] — 脓毒症与感染性休克 | [[]] — 心梗→心源性休克 | [[]] — PE→梗阻性休克 | [[]] — 心包填塞

## 关联系统骨架
- [[骨架/心血管系统]] ← 心源性休克（心梗/心肌炎/终末期心衰）/ 梗阻性（PE/心脏压塞）/ 心源性→分布性
- [[骨架/血液系统]] ← 出血→低容量性休克 / DIC
- [[骨架/呼吸系统]] ← 张力性气胸→梗阻性休克 / ARDS→分布性→顽固低氧
- [[骨架/泌尿系统]] ← AKI（休克最常见的MODS→肾前性→ATN）
- [[骨架/内分泌系统]] ← 肾上腺危象（Addison→皮质醇↓=儿茶酚胺反应缺失→难治性分布性休克→氢化可的松100mg IV！）
- [[骨架/消化系统]] ← 肝衰竭→乳酸清除↓→乳酸酸中毒加重
- [[骨架/免疫系统]] ← 脓毒症（全身炎症反应）/ 过敏反应
