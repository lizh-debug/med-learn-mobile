# 腹部压痛

> **一句话**：压痛=壁层腹膜受刺激→锐痛定位精确。压痛+反跳痛+肌紧张=腹膜刺激三联征=急腹症！需要立即明确病因（阑尾炎/胆囊炎/穿孔/胰腺炎/肠梗阻/肠系膜缺血）。"压在哪里+有没有反跳痛+有没有肌紧张"是查体三问。

## 鉴别矩阵

| 压痛部位 | 常见病因 | 关键伴随体征 |
|---------|---------|------------|
| 右上腹 | 急性胆囊炎（Murphy征+）· 十二指肠溃疡穿孔 · 肝脓肿 · 肝炎 | Murphy征（吸气时触压右上腹→剧痛停吸=急性胆囊炎） |
| 中上腹 | 急性胰腺炎 · 胃溃疡穿孔 · 早期阑尾炎（内脏痛阶段） | Grey-Turner/Cullen征→重症胰腺炎 |
| 左上腹 | 脾梗死/破裂 · 胃溃疡 | Kehr征（左肩痛=脾破裂→膈下积血刺激膈神经） |
| 右下腹 | 急性阑尾炎（McBurney点）· 克罗恩病 · 异位妊娠 · 卵巢扭转 | McBurney点压痛+Rovsing征（按压左下腹→右下腹痛=阑尾炎特征） |
| 左下腹 | 憩室炎 · UC · 异位妊娠 · 卵巢扭转 | |
| 弥漫 | 肠穿孔→弥漫性腹膜炎 · 肠梗阻 · 肠系膜缺血 | 板状腹（弥漫性腹膜炎）+ 肠鸣音消失 |

## 反向追溯

### 🟢 基础层前置
- [[]] — 腹膜解剖（壁层=躯体神经→定位精确+锐痛；脏层=自主神经→牵拉/缺血/痉挛→定位模糊+钝痛。炎症从脏层渗透到壁层→压痛→反跳痛→肌紧张）
- [[]] — 腹部内脏神经支配（前肠=腹腔神经节→上腹；中肠=肠系膜上神经节→脐周；后肠=肠系膜下神经节→下腹）
- [[]] — 牵涉痛机制（内脏传入+体壁传入→同一脊髓节段→大脑"误判"疼痛来源。阑尾→T10→脐周痛；胆囊→T6-9→右肩胛下）

### 🟡 桥梁层
- [[]] — 腹膜炎病生（化学性→细菌性→SIRS；细菌易位→脓毒症；第三间隙液体丢失→低容量）
- [[]] — 肠梗阻病生（单纯性→绞窄性→肠壁缺血→细菌易位→脓毒症。关键是判断有无绞窄——压痛进行性加重=绞窄危险信号）
- [[]] — 急性胰腺炎病生（酶激活→自身消化→从间质水肿到坏死→SIRS→MODS）

## 关联系统骨架
- [[骨架/消化系统]] ← 绝大多数急腹症
- [[骨架/泌尿系统]] ← 肾盂肾炎/肾结石（牵涉到侧腹+脊肋角叩痛）
- [[骨架/生殖系统]] ← 异位妊娠/PID/卵巢扭转（女性下腹痛=先排除妇科急症！）
- [[骨架/心血管系统]] ← 腹主动脉瘤破裂（剧痛+低血压+搏动性腹部包块）
